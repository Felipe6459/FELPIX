# FELPIX

Protótipo inicial de um jogo de plataforma 2D para celular.

## Versão 0.1
- Controles touch e teclado
- Personagem, plataformas, moedas e inimigos
- Pontuação
- Primeira fase com chegada
- Sem dependências externas

Próximas etapas: arte original, áudio, fases, sistema de progresso e Supabase.
